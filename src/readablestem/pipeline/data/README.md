# Data files of the pipeline

## words-en.txt.gz

A list of 63,849 lower-case English words, one per line, sorted, gzip-compressed (168 KB).
`pipeline/hyphens.py` uses it to decide whether a hyphen at the end of a line was put there
by line breaking ("veloc-" and "ity") or belongs to a compound ("well-" and "known"). It is
read only to answer "is this a word"; no text from a document is ever compared against
anything outside the machine.

| Field | Value |
|---|---|
| Source | the Debian/Ubuntu `wamerican` package, version 2020.12.07-4build1 (`/usr/share/dict/american-english`), built from SCOWL (Spell Checker Oriented Word Lists) by Kevin Atkinson, http://wordlist.sourceforge.net/ |
| Licence | the SCOWL permission notice (a permissive licence: use, copy, modify, distribute and sell the lists "for any purpose ... without fee", provided the copyright notice and the permission notice appear in all copies); the text is below and in `THIRD_PARTY_NOTICES.md`. The parts SCOWL takes from the Moby word lists are public domain |
| Filter | only entries made of two or more letters a-z, all lower case: no proper nouns (they start with a capital), no possessives, no single letters, no abbreviations with punctuation |
| SHA-256 of the `.gz` file | `1e2e548ab2be7d641a24470ec121034f6d9b03f36df8a0b66fbe2ecaddbfbb8e` (`tests/test_layout_hyphens.py` fails if it stops matching) |

Rebuild (the file is byte for byte the same on any machine with the same package):

```
python3 -c "import re,gzip,io; ws=sorted({w.strip() for w in open('/usr/share/dict/american-english') if re.fullmatch(r'[a-z]{2,}',w.strip())}); b=io.BytesIO(); f=gzip.GzipFile(fileobj=b,mode='wb',mtime=0,compresslevel=9); f.write(('\n'.join(ws)+'\n').encode()); f.close(); open('words-en.txt.gz','wb').write(b.getvalue())"
```

## glyph-names.tsv

Glyph name to character, one `name<TAB>HEX` row per line (5,433 rows, 99 KB, sorted).
`pipeline/glyph_names.py` reads the name an embedded font gives a glyph and looks it up here,
for the glyphs MuPDF cannot decode: TeX's extension fonts (CMEX10, CMEX9, txex,
LMMathExtension10) name their sum and integral signs, radicals, big brackets and the pieces of
built-up ones, and the file's table to Unicode has no row for them. Only the glyph names of the
font in the PDF in hand are read; no text from a document is compared with anything outside
the machine.

| Field | Value |
|---|---|
| Source | two TeX files, as TeX Live (texlive-base 2025, Debian/Ubuntu package) ships them: `tex/generic/pdftex/glyphtounicode.tex` (pdfTeX's glyph names to Unicode, generated by lcdf-typetools 2.95 from Adobe's glyph list 2.0 and TeX's own names) and `tex/latex/latex-lab/glyphtounicode-cmex.tex` (the glyphs of the cmex fonts; Han The Thanh, Peter Selinger, Ross Moore). Where the second names a glyph the first also names, the second wins |
| Licence | the latex-lab file is under the LaTeX Project Public License 1.3c (TeX Live's `Licenses` file lists `latex-lab: lppl1.3c`); the pdftex package, which holds the first file, is listed there as GPL; the Adobe glyph list it was generated from is BSD-3-Clause. The table is facts (a glyph name and the character it stands for), but the licences of the two source files have not been settled: **open question for the owner** (`THIRD_PARTY_NOTICES.md`) |
| Filter | the variation selectors U+FE00 to U+FE0F, which TeX uses to mark a sized variant, are dropped (`summationdisplay` is the sum sign); a name that stands for more than one character, a private-use code point or a control code says nothing and is left out |
| Added by hand | the pieces the files leave without a character or give a combining mark: `integralex` U+23AE, `arrowhorizex` U+23AF, `vextendsingle` and `radicalvertex` U+23D0, `vextenddouble` and `arrowvertexdbl` U+2016 (`UNICODE_PIECES` in the script) |
| SHA-256 of the inputs | `glyphtounicode.tex` `395e568c1f4db5e89013e6aa4aac22a668b543256a20b4349436070356870851`; `glyphtounicode-cmex.tex` `882b003b5d22a53d6ef52099e5a846e673a05ec0ef211871a2b7f18a0388c4f0` |

Rebuild (the same inputs give the same file):

```
python3 scripts/make_glyph_names.py
```
