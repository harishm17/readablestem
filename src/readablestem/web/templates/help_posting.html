Posting the file in your course

The file you download is one web page (an .html file) with everything built in: the text, the equations and the images. Upload the file and link to it. Do not paste it into a page.

At a glance

  • Canvas, as a file: upload the .html file to Files and link to it where the PDF was.
  • Canvas, as a page: use the separate download, “For Canvas (zip with images)”, and follow its README.
  • Blackboard, Moodle, D2L (not tried yet): upload the file and link to it, or import the Common Cartridge. Do not paste it into a page.
  • Every system: open the result as a student would, and check one picture and one equation.

The job page also offers the same document as {% if word_export %}Word (.docx) or {% endif %}EPUB, with the equations kept as equations, for students who want it in another app. Post the web page as the main version and offer these beside it.

In Canvas, as a file

  1. In your course, open Files and upload the .html file.
  2. Link to it where students look for the material: in a module (add an item, then choose the file), or from a page with the editor's link to a course file.
  3. Where the PDF was linked, link the HTML file instead, so students find it first.
  4. Open the link once as a student would (Student View). Check that the figures show and the equations display.

Do not paste the file into a Canvas page, and do not paste its code into the page editor. Canvas removes what the file needs: its images (they are stored inside the file, and Canvas only keeps images that live at a web address) and its styles, so figures disappear, list numbers can show twice, coloured text loses its colour, and wide tables can no longer be scrolled from the keyboard. In some tables, the links between each value and its headers are removed too, so screen readers stop saying which row and column a value belongs to. (The page in the Canvas zip, below, is made differently so that it can be pasted.)

In some Canvas courses an .html file in Files downloads instead of opening. Students can still open the downloaded file in any browser. If this happens in your course, please tell us{% if contact_email %} at {{ contact_email }}{% endif %}.

In Canvas, as a page

Steps for a Canvas page

Canvas's page editor keeps the text, headings, lists, tables and equations of pasted HTML, but removes style blocks and any image stored inside the page. The job page has a second download for this, For Canvas (zip with images): the pictures are separate files and the styles are written into the page itself.

  1. On the job page, type your Canvas course number (the number after /courses/ in your course's web address) and download the zip. Without the number the zip has the web page and its pictures to link, but no page to paste.
  2. In your course, open Files, make a folder with the name the README in the zip gives, upload the zip into it and choose to expand it.
  3. Make a new Page, switch the editor to its HTML view, paste the contents of canvas-page.html and save.
  4. Open the page in Student View. Check a picture and an equation.

The README in the zip repeats these steps with your folder name and course number. A pasted page still loses three things: the setting that lets a keyboard user move into a box that scrolls sideways (wide tables and equations), the links between cells and headers in an irregular table, and the bold of labels such as “Not converted.” The README says which of these apply to your document.

These steps follow Canvas's published rules for files and pages (the sanitizer in its open-source code). We have not yet tried them in a live Canvas course, and your Canvas may differ: check one picture and one equation.

As a Common Cartridge (Canvas, Blackboard, Moodle, D2L)

Steps for a Common Cartridge

The job page also offers Download as a Common Cartridge (.imscc): the same page and its pictures in the package format that learning management systems import.

  1. In Canvas, open Settings, then Import Course Content; choose Common Cartridge 1.x Package and select the .imscc file. (Other systems have a similar import for Common Cartridge files.)
  2. Open the imported material as a student would, and check a picture and an equation.

We have not yet tried this in a live course. Canvas may bring the page in as a file or as a page, and you may need to link it from a module yourself.

Listen before you post

What Listen shows, and what it is not

On a finished document, Listen as a student shows roughly what a screen reader will say for the converted file, in reading order: headings and their levels, lists, links, equations, figures and tables. You can read it as text, or play it with your browser's own voice. Try it on the demo.

What it is not: a screen reader. NVDA, JAWS and VoiceOver each speak differently, and they treat tables, links and equations in their own ways. It does not test the file or replace listening with the screen reader your students use, so try one of those before you rely on it. The transcript is not part of the file you download. Playing uses a voice on your device unless you choose an online one; some browsers send the text of an online voice to the company that makes the browser.

Make it the main version

Why the HTML comes first

Post the HTML as the main course material, where students look first. If students also want to print, you can keep the PDF as a print copy: link it after the HTML and call it that, for example “Week 3 notes (PDF, print copy)”.

Why the HTML comes first: the federal rule for public universities (28 CFR 35.202) allows a separate accessible version only when the main material cannot be made accessible for technical or legal reasons. The Justice Department's fact sheet on the rule says that, usually, there should not be an inaccessible main page with a separate accessible version beside it.

Other course systems

We have not tried Blackboard, Moodle or D2L Brightspace yet. Upload the file and link to it there too. Do not paste it into a page: Moodle, for example, removes the equations and the images from pasted content.

Check with your accessibility office

This page is guidance, not legal advice. Your campus accessibility office can say what your courses need, and can help with documents this tool does not handle well (see the known limits).
