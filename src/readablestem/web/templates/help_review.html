Reviewing a converted document

The tool converts what it can and asks you about what it is not sure of. The review screen shows each question beside the page of the original it comes from. You answer each one, and then the document is ready to post.

At a glance

  • Open it: on a finished document, choose Review.
  • Each decision: compare the proposal with the original page, then choose Accept, change it, or keep the original.
  • Many at once: “Accept many equations” and “Accept many figures” take the ones that passed every check, after you look at them.
  • Mistakes: after each decision, Undo takes it back.
  • Done: the screen says “All decisions made.” The checks look at the structure of the file, not at whether it says what you meant, so read the student version and listen to it before you post.

What the screen shows

The page title is “Review” and the file name. Under it, one line says where you are: “3 decisions to make.”, “2 of 3 decisions left.”, or “All decisions made.” A numbered row (or, with many decisions, a bar) shows “1 of 3 decided”; each number is a link to that decision.

  • The decision. It is headed “Decision 2 of 3” with a label, “Needs your decision” or “Decided”, and a sentence about why the tool asked. Choices are buttons. Links take you to the previous and the next decision.
  • The page. It is headed “Page 4 of 12” and shows the original page as an image with a mark on each item. A mark is a link to its item. The key above the page says what the marks mean: “Needs your decision”, “Same decision, other page”, “Optional item” and “Accepted”. “Show accepted” and “Hide accepted” turn the accepted marks on and off. “Previous page” and “Next page” move through the pages, and a list of pages says which have decisions to make.
  • On a phone the decision comes first and the page below it. A bar at the bottom of the window, with “Decision” and “Page 4”, goes to either one.
  • Links above the decision: “List view” (every item in one list, with a filter), “Accept many equations” and “Accept many figures” when they are offered, and “Results”, which goes back to the document's page.

A skip link, “Skip to the decision”, goes straight to the decision. After a decision, the screen shows what it did (for example “Accepted.”) with an Undo button, and the next decision still waiting comes up. “More about this item” (on a group of items, “More about this decision”) opens the details: the tool's confidence, the checks that failed, and “Report this item”.

If you have text typed into a box that you have not saved, it is kept in this browser tab and put back when that decision is shown again. It is not sent to the server until you save, and it is gone when you close the tab or sign out in it. If the same document is open in two tabs and the other one changed the item you are saving, that save is refused and nothing is saved; the page says so and offers “Reload this page”. A change the other tab made to a different item does not stop your save.

The kinds of decision

Each decision names its kind and a number, such as “Equation 3” or “Table 2”. The buttons below are the ones the screen shows for that kind.

Equations

The screen shows the original equation as an image and the proposal at the same size beside it, with how the proposal reads aloud and what a screen reader would get from the PDF's own text. A table headed “What differs” lists symbols that differ between the PDF's text and the proposal, and says whether each “Changes the meaning”.

  • Accept keeps the proposal as it is. When the proposal changes the meaning from the PDF's text, the button says Accept anyway. That keeps the differing meaning.
  • When the checks point to one repair, a first button offers it. It saves the change and checks again.
  • {{ strings.READ_AGAIN }} has the model read the picture once more and replaces the proposal. Not an equation gives it back to the page as text, as the PDF has it. Each appears only when it can be used.
  • Edit the LaTeX opens a box. Save edit checks your LaTeX against the PDF and saves it. If your LaTeX differs from the PDF in a way that changes the meaning, the save is refused, and then Use my edit anyway appears.
  • Keep as image shows students a picture of the original. Screen readers read the characters the PDF holds for it, and warn first where fractions and exponents may run together. For a LaTeX source with no picture to keep, the button is Leave as written: students see the LaTeX as it was written, marked “Not converted”.
  • Sometimes another reading of the same picture differs in a few symbols. Then a section named “A second reading differs” offers one button for each reading, such as “Use ...”. Nothing is chosen for you.
Figures

The screen shows the figure and its caption, and the proposed alt text in a box. The hint under the box says how long alt text may be.

  • Accept keeps the proposed alt text.
  • Save and accept saves what you wrote in the box and accepts it in one step. After a figure is decided, the button is Save changes. Save, decide later saves your text and leaves the figure waiting.
  • Decorative: adds nothing, so no alt text is a box to check, for a figure that adds nothing.
  • A longer description, and a data table read from a chart, appear when long descriptions are on. You can remove the data table (“Remove the data table (keep the descriptions)”) or add an optional one (“Add the data table”).
  • Keep without a description is under “If you cannot describe this figure”. You check “I understand: screen reader users get no description.” first. The figure then stays, marked “Needs a description”.
Tables
  • Accept keeps the table. If no cell is a header, there is no Accept: you choose Use the first row as headers, Use the first column as headers, Use the first row and column as headers or This grid is not a table. Screen readers read each header with its cells.
  • Use the grid read from the PDF gives students the grid as a table, as read from the PDF. Compare it with the image first.
  • This grid is not a table writes its words in order, without rows and columns.
  • Change the table opens a list of cells. Pick one and choose Change this cell, then Save cell. Read this cell with the model reads one cell again and checks what it reads like a typed edit.
  • Keep as image shows students a picture marked “Not converted”. Screen readers get no table.
  • When two or more tables wait with nothing found wrong, a button Accept all N clean tables (with the number) accepts them in one step. Undo takes them all back.
Headings
  • Accept keeps the heading as proposed.
  • Make bold text (or Make plain text) keeps the words but takes the line out of the outline.
  • A level box (“Level 1” to “Level 6”) and Save edit change the level. The screen says which levels fit.
  • When the same words repeat on many pages, such as a running header, they become one decision. It says how many times they appear and suggests an answer. Keep as headings and Make bold text decide all of them. Choose another level sets one level for all, and Decide them one by one shows each with its own two buttons.
Paragraphs, scanned text and notes
  • For a paragraph or list item the tool asks about, including text read from an image of a scanned or handwritten page, the screen shows the words beside the page. The buttons are Looks right and a button that keeps the original, named for what it does (for text read from an image, “Keep as image”). Change the words opens the page tools (below).
  • A note titled “Worth a look” says that something in a paragraph may need a look, such as a link or a line. Nothing holds up the document: change the words if you agree, or leave it.

Choices that work the same way everywhere

  • Accept keeps the proposal as proposed. The line under it says so.
  • The button that keeps the original is named for what it does for that kind of item, such as “Keep as image” or “Make bold text”, and the line under it says what students get.
  • Save edit saves a change you typed. The screen says “Your edit passed the required checks and was saved.” Once you change a field, Save edit becomes the main button. If you press Accept with a changed field, nothing is accepted and the screen says “Choose Save edit to use your change, or undo it to accept the proposal.”
  • Hear this plays the proposal aloud with your browser's own voice. It appears only when your browser has one. It is not a screen reader.
  • Undo takes back the last decision. It is offered on the screen that the decision made, and it covers a whole “accept many” step in one press.

Keyboard shortcuts

Under the decision, a group named “Keyboard shortcuts” has a box, “Use keyboard shortcuts”. It appears when JavaScript is running. The shortcuts are on until you turn them off, and the choice is remembered in your browser.

N
next decision
P
previous decision
A
accept
E
edit (go to the field)

The list under the decision names only the keys that decision can use: a table kept as a picture has no Accept, so A is not listed there, and the last decision has no N.

A key does nothing while you type in a box or hold Ctrl, Alt, Shift or Command. If a key has nothing to act on, the status line says so. A never presses “Accept anyway”, and it never presses a choice that decides a whole page. Those need Tab and a press. Everything also works without the shortcuts.

Accept many at once

Two kinds can be accepted in a group: equations and figures. The links “Accept many equations (N)” and “Accept many figures (N)” appear when at least two are waiting with every check passed. For equations, that also means the second automated check found nothing. For figures, it means the alt text was generated and is not marked decorative.

The link opens a list of those items, {{ bulk_page_size }} to a page, each with the original and the proposal. The button on the list (“Accept these N equations” or “Accept these N alt texts”) accepts the ones listed on that page and nothing on the other pages. “Cancel” goes back. Anything that failed a check or was flagged stays for you. Undo reverses the whole step.

Change a page

Under the optional items, a disclosure named “Change page 4” (with the current page number) has three tools. On the document's page, the link Fix something on a page opens the same tools for page 1 even when no decision is waiting. After a change here, the screen offers Undo this change.

  • Change the words, make a line a heading, set a paragraph apart, or leave it out. Choose a paragraph, a list item or a heading on the page, change its words, and choose Save the words. Make it a heading turns a line into a heading at the level you pick. Make it a sidebar or Make it a quotation sets a plain paragraph apart on the student page, and Not a sidebar or Not a quotation takes that off again. Leave it out takes a paragraph or a list item out of the student file, for text that is on the page but is not for the student, such as a running head or a stamp. The student file says that text was left out, the record keeps its words, and Put it back on the page's list gives it back. A heading, an equation, a figure, a table, a footnote or a text something else links to cannot be left out. An equation, a figure or a table is changed in its own decision, not here. A link on words you change is taken off.
  • Add something the tool missed. Say whether it is “A picture or diagram” or “An equation on its own line”, and give its place on the page: either as numbers from 0 to 100 for the left, top, right and bottom edges, or by choosing the line it starts after and the line it ends before. Show the part I described shows it cut out before anything is added. Then Add the picture (with its alt text) or Read it as an equation. The tool reads the equation and you look at it as a decision. Change the region goes back to the numbers.
  • Leave this page out. For a blank page or a cover. The page is left out of the student file and of the review, and the file says that it is not there. Nothing is deleted: Put page N back restores it. The last page left in a file stays.

Optional items

“Optional items (N)” lists items the tool accepted for you, each with a small note. Nothing needs doing unless you disagree: choose one to open it and change it. “Your decisions (N)” lists what you decided.

Decisions you leave open

A decision you leave open is not decided for you. The document stays a draft until every decision is made. When only lower-risk decisions are left (a reading that passed every check with lower confidence, or a heading that repeats), the screen says so, and says again that the document stays a draft.

  • On the document's page the status says how many decisions need you before you give it to students, and the main button is Review.
  • If you try to download it anyway, a page asks first: “Download a draft of ...?” It says what students would get: for each undecided item, the tool's suggestion as it is, and items kept as images marked “Not converted”. You can Review N decisions first or Download the draft anyway.
  • A draft's file name ends in “-draft”, and the file opens with the line “Draft: 2 decisions are still open. Not for students.”
  • A person you shared the document with to view only is never given the draft. They are told that the owner is still reviewing.

When the document is ready to post

  • The review line says “All decisions made.” and the decision area shows the finish line with a state, for example “Ready to post”, “Ready” or “Partly converted”, and a sentence on what was reviewed. The same state is on the document's page.
  • “Ready to post” means no decision is open, and the page says “Every item the tool found was converted.” “Ready” and “Partly converted” say what remains, such as items kept as pictures, pages left out, or parts of a LaTeX source it could not read. The page says what it is.
  • When the document can be posted, the screen offers Download the HTML file, Preview the student version and Listen as a student. Read the student version through once and listen to it. The checks look at the structure of the file, not at whether each item says what you meant.
  • Then see posting the file in your course.
