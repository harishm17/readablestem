Where the beta falls short today, the limits on what you can upload, and how accurate it is, with the size of each test.

On this page: what it handles, with limits, what it does not do, limits on use and how accurate it is.

What it handles, with limits

  • Equations. Each equation's proposal is compared with the PDF's own text (letters, digits, signs and letter styles), and a difference becomes a decision for you. A mistake that agrees with the PDF's text, or a PDF with no usable text layer, can still get through. Maths inside a table cell or a figure is often missed.
  • Chemistry formulas and reactions are found and read out as formulas, but it is the weakest area: on a fresh set of textbook sections about half of the equations were right as chemistry. Check every one.
  • Slides. A Beamer deck is read frame by frame: overlay steps that only add to a frame are merged, and each frame title becomes a heading. Lists in themes that draw their bullets as pictures (Warsaw, Madrid) come out as one paragraph, and a sidebar theme's outline is read as a column of text. A deck exported from PowerPoint is read page by page, with every step kept.
  • Tables. {% if tables_on %}A table the tool cannot read as a table of data stays a picture of the original, marked “Not converted”, and you are asked about it. A table without ruled lines can be missed and shown as plain text, sometimes as an equation.{% else %}Tables are not rebuilt yet: each stays a picture of the original, marked “Not converted”, and you are asked about it.{% endif %}
  • Figures. Alt text is short and says what the figure shows.{% if long_on %} A chart or a diagram can also get a longer description, and a chart a table of its values; their quality has not yet been measured on a held-out set, so read them.{% else %} A complex diagram still needs a longer description, which you write.{% endif %} For an exam or quiz, tick the exam box so descriptions leave out the answers.
    • {% if image_pages_on %}
  • Handwritten notes and scanned pages are converted only when you ask. Tick “Convert scanned or handwritten pages” when you upload. Each such page is then read from its picture, which is slower (about 20 to 30 seconds a page) and uses more of the server's budget than a typed page, and you check every converted equation and table before you share the file; the original page stays in the file, behind “Show the original page”, for checking. A tool can misread handwriting and small symbols. On 24 pages of real handwriting that were not used to build the feature, 57% of the equations came out exactly right, every wrong one had a decision, and it asked for about 5.7 decisions a page. On nine real papers made into scans, about 2 in 3 equations came out exactly right. A page whose only text is a watermark, a stamp or a page number over a picture or handwriting counts as scanned or handwritten too. Without the tick, a PDF made only of scans or handwriting is refused before it counts against your daily pages, and in a PDF with typed pages each scanned or handwritten page is kept as an image, marked “Not converted”, and you are asked about it. Handwriting on a typed page is kept as an image either way.
    • {% else %}
  • Handwritten notes and scanned pages are not converted. A PDF made only of them is refused before it counts against your daily pages. In a PDF with typed pages, each one is kept as an image, marked “Not converted”, and you are asked about it. A page whose only text is a watermark, a stamp or a page number over a picture or handwriting counts as scanned or handwritten too. Handwriting on a typed page is kept as an image too.
    • {% endif %}
  • Two-column pages convert less well than single-column notes: check the reading order.
  • Links. A link over a picture or a drawing, or in a figure's caption, is not kept. Link text is kept as printed, even when it says nothing on its own (“click here”): only you can reword it.
  • Colour. {% if colour_on %}Coloured text in paragraphs keeps its colour; colour in headings is not kept.{% else %}Coloured text is not kept: the file uses its own colours.{% endif %} Colour inside figures stays in the picture.
  • Language. The language is worked out from the text and needs about 20 words of prose. A short handout that is mostly maths is assumed to be English unless the PDF says otherwise. A passage in another language is marked only when it is a whole paragraph or list item.

What it does not do

  • Hidden text is never used. Text that a tablet or a text recognition (OCR) program guessed and hid in the PDF, and text that cannot be seen when the page is shown or printed, is left out. Running OCR does not help: OCR text is often wrong, most of all in maths. Some hidden text is not detected: white text on a white page, text under a drawn shape that only partly covers it, very small text, and OCR text that is visible on the page.
  • Maths in headings stays as plain characters in the text, not as MathML equations: check how it reads.
  • File types. {% if office_on %}PDF files, and Word (.docx) or PowerPoint (.pptx) files, which are turned into a PDF first.{% else %}Only PDF files are taken. For a Word or PowerPoint file, save a copy as a PDF first.{% endif %} It works from the PDF, not from LaTeX source files.
  • The checks look at structure, not meaning. Every file is checked for structure (language, title, headings, lists, image text alternatives). The full axe-core accessibility test runs on our own test documents, not on yours, and nothing here replaces testing with a screen reader.
  • No certification. The tool assists you. It does not say that a document meets WCAG, the ADA, Section 508 or any other standard or law.

Limits on use

  • Daily limits. {% if signup_open %}A new account (one you made by signing in) can convert {{ open_page_quota }} pages and start {{ open_rereads }} reads with the model from the review screen (marking an equation, reading a table cell) a day{% if invited_page_quota %}; an invited account can convert {{ invited_page_quota }} pages a day{% endif %}. New accounts also share a small part of the day's budget for model calls: when it is used up, conversions for new accounts pause until midnight UTC while others go on. New accounts are limited in number each day too. {% elif invited_page_quota %}You can convert {{ invited_page_quota }} pages a day. {% endif %} All limits start again at midnight UTC, and the whole service pauses for the day when its budget for model calls is used up. When several people upload at once, the queue takes one document from each person in turn.
  • Size. Up to {{ max_pages }} pages and {{ max_upload_mb }} MB per upload. {% if in_parts %}A bigger file, up to {{ source_pages }} pages and {{ upload_limit_mb }} MB, is kept for a day so you can choose which pages to convert; each part becomes a document of its own. When two or more parts are finished, a “Combine parts” link on a part's page joins the ones you still have into one file, in page order; a part you deleted is left out.{% else %}Split longer documents.{% endif %}
  • Your documents are deleted {{ retention_hours }} hours after you last worked on them (7 days if you choose to keep them, {{ opt_in_days }} if you also let us look at the results). Download the file before then.
  • Review time. How many decisions a document needs depends on what it is. In the held-out tests below: textbook sections, about 1.8 decisions a page (15 OpenStax sections, 242 pages); research papers made with LaTeX, about 5.6 a page (15 arXiv papers, 71 pages){% if image_pages_on %}; handwritten notes, about 5.7 a page (24 pages){% endif %}. Once your document is converted, its page tells you the exact count. Where the checks found nothing wrong, you can accept all the equations, or all the figures with alt text, in one step after seeing the list.

How accurate it is

{% include "_proof_strip.html" %}

The main result is a pre-registered test on 15 sections of five OpenStax textbooks that the tool had not seen (version 0.4.0, October 2026; full results):

  • Equations: it found about as many as a general chatbot (Claude Opus given the PDF and one sentence), 89% of them in both cases, but fewer came out exactly right end to end: about half (0.50) against 0.62 for the chatbot. Given each equation on its own, about two in three were right (0.68).
  • Headings: F1 0.96, with every matched heading at the right level. (F1 is a score out of 1 that counts both headings missed and headings invented.)
  • Figure descriptions: 97% passed a model judge, a second AI model asked whether each description is right (not yet checked by people).
  • Decisions it asked for: about 1.8 per page; it asked about only a third of the equations that were wrong.

On equations it does not yet beat the chatbot end to end. The other measurements:

  • Research papers typeset with LaTeX, held out (15 arXiv papers, 71 pages, 1,826 equations, registered before the run): 0.58 of equations exactly right end to end, against 0.64 for the chatbot on Opus and on Haiku. The set is too small to show a difference. It asked for about 5.6 decisions a page. How it was measured.
  • The same 15 textbook sections, measured again (2026-10-21, version 0.5.0 and later): 0.596 of equations exactly right end to end, against 0.504 in the registered run and 0.622 for the chatbot. This is not a blind result: those sections had been examined since the registered run, so the numbers are optimistic. How it was measured.
  • Development set, not held out (25 arXiv papers, 114 pages, 2,350 equations, 2026-11-03, with the settings the live service uses): 0.735 exactly right end to end, against 0.675 for the chatbot on Haiku; on the 6 papers with an Opus answer, 0.764 against 0.784. These papers were used to build and tune the tool, so expect less on your documents. The development report.
  • Chemistry, held out (5 OpenStax chemistry sections, 377 equations): 0.56 right as chemistry, and 0.14 exactly right on the strict score. The chemistry report.
  • Handwriting, held out (24 pages, 205 expressions): 0.57 exactly right end to end, with no wrong equation left without a decision. The handwriting report.

Real course PDFs, especially ones typeset with LaTeX or exported from Word, may do worse. The evaluation report says how this was measured and what the numbers do not show.
