Look: static/app.css, "Forms" and "Errors". field(id, label, error, hint, ...): the ordinary field, a label, a hint, the message and one control. Used as `{% call(aria) field("email", "Email address", error=err, hint="...") %}` around the control, which writes `{{ aria }}` among its attributes: `aria-describedby` (the hint and the message, then `describedby`) and, in error, `aria-invalid="true"`. `id` is the control's id; the hint is `ID-hint` and the message `ID-error` unless `hint_id` or `error_id` say otherwise (a route, a test or the error summary's link may depend on an id). `error` is a message, or an object with a `.message` (a form error). `hint` is text, or a block set (`{% set hint %}...{% endset %}`) when it holds markup. `extra` adds classes to the wrapper (`file-field`, `field-inline`, `checkbox-field`).
