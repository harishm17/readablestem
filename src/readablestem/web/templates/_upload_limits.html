Daily limits
{% if signup_open %}A new account (one you made by signing in) can convert {{ open_page_quota }} pages and start {{ open_rereads }} reads with the model from the review screen (marking an equation, reading a table cell) a day{% if invited_page_quota %}; an invited account can convert {{ invited_page_quota }} pages a day{% endif %}. New accounts also share a small part of the day's budget for model calls: when it is used up, conversions for new accounts pause until midnight UTC while others go on. Pages dense with equations use more of that share than plain pages, so it lasts for fewer of them. New accounts are limited in number each day too. {% elif invited_page_quota %}You can convert {{ invited_page_quota }} pages a day. {% endif %} All limits start again at midnight UTC, and the whole service pauses for the day when its budget for model calls is used up. When several people upload at once, the queue takes one document from each person in turn.
Storage
You can keep up to {{ storage_mb }} MB of uploads and results at once{% if signup_open %} ({{ open_storage_mb }} MB for a new account){% endif %}. An upload that would go over is refused; delete documents you no longer need to make room. When the service as a whole is full, uploads wait until older documents have been deleted.
How long it is kept
Your documents are deleted {{ retention_hours }} hours after you last worked on them (7 days if you keep them, for one upload or as your default in Account; {{ opt_in_days }} if you also let us look at the results). Download the file before then.
