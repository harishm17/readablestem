For accessibility offices

ReadableSTEM assists instructors who turn a STEM course PDF into an accessible web page. This page is for the office that decides whether instructors may use it.

It describes the beta as it works today. It is not a contract or an audit. Download the one-page summary (an HTML file that prints on one page).

Where a document goes

The steps in words
  1. The instructor signs in and uploads a PDF{% if latex_source %} (or a LaTeX file or a zip of a LaTeX project){% endif %} over HTTPS to the ReadableSTEM app, which Railway hosts in the United States.
  2. The app opens the PDF in a separate short-lived process and cuts out images of the equations and figures{% if tables_on %} and tables{% endif %}, with a little of the nearby text.{% if latex_source %} A LaTeX file or project is read on the server instead, with LaTeXML in a sandbox: its equations come from the source, and its figures are described as a PDF's are.{% endif %}
  3. Those images and that text are sent to the API of {{ model_names }}, which returns proposed LaTeX and descriptions.{% if notation_on %} For a document uploaded for one of the instructor's courses, that course's notation (its symbols and what they mean) is sent with the equations.{% endif %}{% if image_pages_on %} If the instructor checks “Convert scanned or handwritten pages”, a picture of each such page is sent as well.{% endif %} The PDF file itself, its file name and the instructor's email address are not sent.
  4. Automatic checks compare each proposal with the PDF's own text. The instructor decides what the tool is unsure about and can edit anything. A document can be shared with named colleagues, who must sign in with the exact email address entered.
  5. The instructor downloads the result and posts it in the course: a web page (one HTML file), and if wanted the same document as {% if word_export %}Word, {% endif %}EPUB, a zip for a Canvas page or a Common Cartridge.

Student records (FERPA)

No data agreement is offered. ReadableSTEM does not sign a school-official agreement or a data processing agreement. If your institution requires one for any tool that handles course material, ReadableSTEM does not meet that yet. Students never sign in to ReadableSTEM.

What is and is not processed
  • Processed: the instructor's course material, and the instructor's email address, name and sign-in id.
  • Not processed: student names, grades, submissions or accounts. Students open the converted file in their browser and never sign in to ReadableSTEM.

The terms forbid uploading student records, graded work or anything with students' personal information. This page is not legal advice. Your privacy or legal office decides what applies.

What the tool does not certify

It assists the instructor. It does not make a document accessible by itself, and it does not say that a document meets WCAG, the ADA, Section 508 or any other standard or law.

More on what it does not do
  • Its proposals can be wrong: the chart above is the measured result, and the evidence page has all of it, including earlier tests. In 3 chemistry sections, 0.33 of the equations were right as chemistry. The tool asks the instructor about the parts it is unsure about and accepts the rest on its own checks.
  • The automatic checks look at structure (language, title, headings, lists, tables, links, the alt attribute of images), not at whether a description or an equation reading is right.
  • The output has not been tested by listening with NVDA, JAWS or VoiceOver, and it has not been tried in a live course site.
  • There is no accessibility conformance report (VPAT) published for the ReadableSTEM web application itself. A report in the VPAT 2.5 layout (WCAG 2.2, levels A and AA) is in preparation; it will say what has been tested and claim nothing more. Automated tests walk every page of the app with the keyboard alone and run axe-core on the main screens.
  • There has been no independent security test.
  • Scanned and handwritten pages are converted only when the instructor asks, and a person must check each converted equation and table. Chemistry is the weakest area. All known limits.

Pilot checklist

A small trial for one course. Each step is for the office or the instructor to do.

The eight steps
  1. Pick one course and one document the instructor wrote or may adapt, with no student records in it.
  2. Read the privacy notice and this page with your privacy or legal contact, and decide whether the data flow and the companies above are acceptable.
  3. The instructor signs in, uploads the PDF, and works through every decision on the review screen.
  4. Check the downloaded file with your own screen readers (for example NVDA, JAWS or VoiceOver): equations, headings, figure descriptions and tables.
  5. Check the file with the checker and the review your office normally uses, against the standard your institution applies. ReadableSTEM makes no claim about the result.
  6. Post the file as described in Posting in your course, then open it as a student would.
  7. Download the file and the review record (a page to print, and a CSV) before the document is deleted, and keep them where your office keeps its own records.
  8. Tell us what was wrong or missing, using “Report this item” on the review screen {% if feedback_url or contact_email %}or the feedback link in the footer{% endif %}.

Support and continuity

  • The code is open source, so your institution can run its own copy: the source code and how to deploy it. The license terms are on the terms page.
  • Nothing is locked in. Every result can be downloaded as a web page, {% if word_export %}Word, {% endif %}EPUB and a Canvas package, with the review record.
  • If the hosted service ever closes, a notice goes on this page first. Stored documents are then deleted on their usual schedule (see Privacy), so no copy is left behind.
  • There is no support contract or service-level agreement. To report a problem, use “Report this item” on the review screen{% if contact_email %} or email {{ contact_email }}{% endif %}.
