ReadableSTEM, Mathpix and LaTeXML compared

Last updated {{ updated_text }}. By Harish Manoharan, who made ReadableSTEM. The facts about the other two tools come from their own documentation, read on 28 October 2026 and linked under Sources.

The right tool depends first on the file you have. This page sets out what each tool takes in and gives back, what it automates, and what it costs, so you can choose. Where another tool fits your file better, it says so.

Start with the file you have

  • You have the LaTeX source. LaTeXML is the better fit. It converts the source itself, so nothing has to be recognized from a PDF. ReadableSTEM starts from the PDF and does not work from LaTeX sources.
  • You have only a PDF and want a web page. Mathpix and ReadableSTEM both do this. Mathpix is a paid service with a free tier. ReadableSTEM is a free beta with a review screen for the instructor.
  • The file has to stay a PDF. Mathpix documents an accessible PDF output (a tagged PDF that keeps the original pages). ReadableSTEM returns a web page, not a PDF. Mathpix is the better fit.
  • You have other formats, images, handwriting or a large batch. Mathpix takes more kinds of input, has an API for batches, and exports to more formats. ReadableSTEM takes a PDF and returns one HTML file, with a zip for Canvas and a Common Cartridge.
  • You want to check each uncertain change before students see it. ReadableSTEM is built around that step. The Mathpix and LaTeXML pages we read describe no such step.

ReadableSTEM

ReadableSTEM assists instructors who need to turn a STEM course PDF into an accessible web page. It reads the PDF, rebuilds equations as MathML a screen reader can speak, restores headings and lists, writes short alt text for figures, and returns one self-contained HTML file. Every change it is unsure about goes to a review screen where the instructor accepts, edits or rejects it.

It assists; it does not certify. Nothing here establishes conformance with WCAG, the ADA or any other standard, and the output still needs a person to look at it. That is what the review screen is for.

It makes mistakes, so look over the equations your students rely on. We have not run Mathpix or LaTeXML on our held-out test, so this page makes no accuracy comparison. The full results compare ReadableSTEM with a general chatbot and three open parsers, including where it loses. It starts from a PDF, and its known limits list what it does not do yet.

Mathpix

Mathpix recognizes printed and handwritten STEM content, including math, text, tables and chemistry diagrams, from images, stroke data or PDF files. Its documentation describes Mathpix Markdown as the main output, with conversion to DOCX, XLSX, LaTeX, HTML, PDF and PPTX. For HTML, equations are SVG by default, and the options include MathML.

It fits when you have more than a PDF to convert: other file types, images, handwriting, a batch of documents or an API. It is also the one to look at if the file has to stay a PDF: its accessible PDF output adds a text layer and PDF/UA tags to the PDF you sent, so that headings, tables and lists are announced as such and formulas are spoken. Mathpix says figures there get a short alternative built from the caption, not a description of the picture.

Mathpix's own page on its HTML output says that headings are headings, tables are tables and equations carry their source, and that alt text for figures is not something recognition can invent, so that remains yours to write.

LaTeXML

LaTeXML converts TeX and LaTeX sources to XML, HTML, MathML and ePub. It was written for the Digital Library of Mathematical Functions at the U.S. National Institute of Standards and Technology (NIST), and the project says plainly that emulating TeX is hard and that there are gaps in fidelity and coverage.

If you have the LaTeX source of your notes or problem sets, it is the better fit: the conversion is automatic, the math comes out as MathML, and it is free. If you only have the PDF, LaTeXML cannot use it. This guide has not tested how accessible LaTeXML's output is; it is a converter, and the result still needs checking like any other.

Check with your accessibility office

This page is guidance, not legal advice. Your campus accessibility office can say what your courses need, and may already license one of these tools. What the rule asks of course materials is in ADA Title II and STEM course materials.
