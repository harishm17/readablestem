Posting the file in your course

The file you download is one web page (an .html file) with everything built in: the text, the equations and the images. Share it by uploading the file and linking to it. Do not paste it into a page.

In Canvas

  1. In your course, open Files and upload the .html file.
  2. Link to it where students look for the material: in a module (add an item, then choose the file), or from a page with the editor's link to a course file.
  3. Where the PDF was linked, link the HTML file instead, so students find it first.
  4. Open the link once as a student would (Student View). Check that the figures show and the equations display.

Do not paste the file into a Canvas page, and do not paste its code into the page editor. Canvas removes what the file needs: its images (they are stored inside the file, and Canvas only keeps images that live at a web address) and its styles, so figures disappear, list numbers can show twice, coloured text loses its colour, and wide tables can no longer be scrolled from the keyboard. In some tables, the links between each value and its headers are removed too, so screen readers stop saying which row and column a value belongs to.

In some Canvas courses an .html file in Files downloads instead of opening. Students can still open the downloaded file in any browser. If this happens in your course, please tell us{% if contact_email %} at {{ contact_email }}{% endif %}.

These steps follow Canvas's published rules for files and pages. We have not yet tried them in a live Canvas course.

Make it the main version

Post the HTML as the main course material, where students look first. If students also want to print, you can keep the PDF as a print copy: link it after the HTML and call it that, for example “Week 3 notes (PDF, print copy)”.

Why the HTML comes first: the federal rule for public universities (28 CFR 35.202) allows a separate accessible version only when the main material cannot be made accessible for technical or legal reasons. The Justice Department's fact sheet on the rule says that, usually, there should not be an inaccessible main page with a separate accessible version beside it.

Other course systems

We have not tried Blackboard, Moodle or D2L Brightspace yet. Upload the file and link to it there too. Do not paste it into a page: Moodle, for example, removes the equations and the images from pasted content.

Check with your accessibility office

This page is guidance, not legal advice. Your campus accessibility office can say what your courses need, and can help with documents this tool does not handle well (see the known limits).

Sources

  • 28 CFR 35.202, conforming alternate versions (Electronic Code of Federal Regulations)
  • Fact sheet: new rule on the accessibility of web content and mobile apps (ADA.gov, U.S. Department of Justice)
