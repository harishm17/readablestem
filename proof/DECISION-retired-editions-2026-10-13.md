# Decision: retired first editions are accepted for the held-out set

Date: 2026-10-13. Decided by Harish ("yes ok"), before any system ran on the held-out sections.

The pre-registered held-out set (PREREGISTRATION.md, section 4.4) uses retired first editions of
College Physics, Chemistry, Precalculus, Introductory Statistics and Intermediate Algebra,
which are CC BY 4.0. The current editions of those books are CC BY-NC-SA 4.0, and the only live
CC BY STEM books (Physics, Statistics) were used in development. This answers ADR 0001 open
question 2 for this evaluation. The pre-registration stands unchanged.
