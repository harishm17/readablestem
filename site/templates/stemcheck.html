A second look with stemcheck

stemcheck is a separate, small tool. It compares an HTML version of a STEM PDF with the PDF's own visible text. It lists the places where the HTML says something the PDF does not.

What it checks

  • A changed digit, sign or letter in an equation.
  • A bold vector that became a plain letter.
  • A reworded answer option, a dropped paragraph or an added hint.

A person decides each place. It uses no model, no text recognition and no network. It is for instructors who want to look at an HTML file before posting it, and for accessibility staff who need a record of the checking done on a converted file. The HTML can come from a chatbot, from a11y-stem or from another converter.

The sample report

The sample is a real run on HTML that a chatbot wrote from two OpenStax Physics sections (2.2 and 2.3, development pages). It is not a11y-stem output.

Open the sample report

The report is one self-contained page of about 2 MB with page images. It opens in the same tab and has no link back to this site: use your browser's Back button to return.

How to read the report

  • It starts with a list of what stemcheck cannot see, then the counts for this run. Read that list first.
  • “Places to look at” are differences, not verdicts. The report never says that a file is correct. No places listed would mean no differences were found in what was compared. It would not mean the HTML is right or accessible.
  • Pages with no usable text layer, such as scans and handwriting, are listed as not checkable.

What it is not

  • It is not an accessibility checker. For that, use axe and a person.
  • It does not judge whether the PDF itself is right.
  • It does not check how a screen reader speaks the maths. The before and after page is about that.

The source and the full documentation are in the stemcheck repository. stemcheck is MIT licensed. It uses MuPDF, which is AGPL-3.0.
